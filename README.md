# Eiram Closet

A mobile-first, local-first personal digital closet.

## Version 1 features
- Personal wardrobe with photos and garment details
- Search and category filters
- Simple outfit matching from owned clothes
- Wada-inspired colour combination explorer
- Wishlist with current and target prices, product links and notes
- JSON backup and restore
- Offline-capable Progressive Web App foundation
- Owner field ready for family profiles later

## Privacy
Wardrobe data is stored in the browser on the device using local storage. It is not uploaded to this GitHub repository. Use **Settings > Export backup** regularly to keep a separate copy.

## Publish with GitHub Pages
In the repository, open **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will provide the public app URL after deployment.

## Note on colour combinations
The current app includes an original curated matching layer inspired by the study of historical Japanese colour combinations. It does not reproduce the contents of Sanzo Wada's book. The palette engine can be expanded in a future version.
